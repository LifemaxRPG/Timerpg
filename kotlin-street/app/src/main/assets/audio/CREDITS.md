# Sound credits

Every recorded sound the game ships, where it came from, who made it and its licence. Only sounds we may redistribute in
the APK are here: CC0 (public domain dedication) first, CC-BY 3.0 with the attribution below. Each licence was read on the
sound's own page before it was downloaded (Freesound: the page's licence link; OpenGameArt: the page's "License(s)" box and
any licence file in the pack). Sounds made by the game's own code (engines, tyres, the far traffic, sirens, the tower bell,
rain, wind, crickets, footstep set E: `audio/*.kt`) need no credit. The files were cut, levelled and re-encoded by
`tools/make_sounds.py` (docs/SOUND.md); nothing else was changed.
