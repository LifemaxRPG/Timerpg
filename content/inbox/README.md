# Content from ChatGPT

Batches written by the scheduled ChatGPT task (prompt: docs/CHATGPT_CONTENT_PROMPT.md). Save each run's JSON here as
`YYYY-MM-DD.json` (or paste it to Claude). Claude validates each batch, rejects what does not fit the simulation, and
turns the rest into game data (story templates, secrets, rumors, legends, dialogue lines, era flavor); mechanic
proposals are reviewed with the owner before anything is built.
