# Public Library — 1912 and later addition

An original 1912 brick-and-stone town library, following `docs/CHATGPT_NEXT_BATCH3.md`: a two-column pedimented portico, raised approach, round-arched reading-room windows, hipped slate roof, central circulation desk and two reading rooms over a basement children’s-room shell. The separate 1970s state adds a low brick/glass reading wing connected through a short glazed link.

## Files and rebuilding

- `public-library-1912.glb` and `public-library-1970s.glb` are complete alternative states. Both retain the same origin and original door anchors. Select one state at a time.
- Matching `.blend` files are editable with all textures packed. `state-1912.json` and `state-1970s.json` give each state’s actual geometry, door and collision data; `model-info.json` combines them.
- Deterministic art/build scripts, shared swatch provenance, actual raw/clean Blender views, review sheet, gallery and actual-file validation accompany them.

From the repository root, with Blender 4.3.2 and Python/Pillow/numpy:

```bash
python prototypes/public-library/make_art.py
blender -b -t 6 --python prototypes/public-library/build_library.py
blender -b -t 6 --python prototypes/public-library/build_library.py -- --later
python prototypes/public-library/validate_model.py
python prototypes/public-library/package_preview.py
```

Use `--review` after `--` for half-size eight-sample views; `--shots=none` rebuilds the model/source/metadata only, and `--shots=01-front-day,03-rear` selects views. Final images use 1280×960, Cycles twenty samples. Optional OIDN 1.4.3 (`oidn==0.2.1` Python wrapper) removes light-sampling noise through `finish_renders.py`; it does not invent or replace geometry. Clean all eight raw images before packaging. The local ZIP excludes itself, caches and Blender backups.

## Art and runtime handoff

- Original footprint: 18.0032×13.968m. Main floor is 1.8624m above grade; the intentional basement floor is 1.2416m below grade. The slate hip reaches 9.6224m. Source Blender axes are Z up/front −Y; exported geometry and all collision metadata use glTF metres, Y up/front +Z.
- Real arched glass perimeters, masonry spandrels, stone surrounds, complete roof pitches/soffits, basement light windows, twelve approach risers and a genuine interior floor opening are modeled. Twenty interior risers connect main floor and basement in two flights, with a half landing and rails.
- All exterior doorways are open, with no closed panels or gate boxes. The original `door_back` anchor is unchanged in the later state, where it opens into the glazed link. Rebind/hide its exterior interaction for that state. New addition doors have their own actual raised landings and stairs.
- The only name lettering is the carved `sign_name` region `[0,0,100,16]` art pixels in `textures/signs.png`. Repaint this region per town; the preview label is PUBLIC LIBRARY. Exterior lanterns light the stone sign; it is not neon.
- Every art pixel is exactly 2×2 texels at 0.0388m/texel. Textures use nearest/repeat sampling; pitched surfaces retain physical UV density. The pane-only emission mask preserves dark frames. Imported alpha glass and lighting need integration.
- Interiors are clean shells with a fixed circulation desk, two reading rooms and the basement room. The game supplies books, shelves, tables, chairs and residents. No collection contents, people, ownership or town history are generated by the asset.
- Collision boxes are **already in glTF coordinates**, under `collision.boxes_gltf_y_up`; do not apply the older Blender-to-glTF rotation again. The exported hidden `collision` mesh matches these boxes. Exterior fixtures are blocked from grade; the upstairs desk blocker starts at its supporting floor so it does not obstruct the basement below. Architectural walls/floors/stairs supply their own contact. Optional `lot` dressing and its tagged colliders must share visibility.
- **Importer work remains:** the current `LandmarkKit.collisionTags` parser reads older Blender-frame keys; it must consume this explicitly labeled glTF key. Intentional basement geometry must not trigger whole-model uplift. Cut terrain under the original footprint and implement height-aware basement/stair navigation. This prototype does not claim those runtime changes are complete.
- The 1912 design fits buildings constructed about 1905–1920; the addition is eligible about 1965–1985. These are state-selection hints, not automatic simulation events. Construction, available rear land and addition timing must follow actual town facts.

Shared brick, stucco, slate, membrane and pavement cuts are retained with provenance. These LimeZu swatches are licensed for Timerpg only; preserve original credit. Supplemental pixel art and all geometry are original.

The images are **Blender desktop previews, not Filament or Samsung Galaxy S25 captures**. Terrain hiding for interior cameras is presentation only. Game integration and phone measurements remain pending.
