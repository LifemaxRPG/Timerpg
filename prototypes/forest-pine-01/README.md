# Tall Forest Pine

Pine 01 is the mature, narrow-crowned canopy tree in the Timerpg forest kit. Its offset, irregular needle whorls sit above a long exposed trunk, suitable for dense stands. The original three-color bark and needle swatches use the Timerpg two-by-two art-pixel grid, 0.0388 m per texel, and nearest filtering. The model has a grade-centered origin and a Y-up GLB. The trunk collision box is provided as placement metadata. Preview scenery is outside the asset.

The Blender file contains the packed swatches. Run `blender -b -P build.py` to rebuild. The image is a Blender daylight render. In-game scatter and collision remain to be tested.
