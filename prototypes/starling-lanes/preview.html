Starling Lanes

An original 1960s bowling alley for Timerpg: folded canopy, vaulted hall, detailed maple lanes, recessed gutters and ten-pin racks, using the shared material atlas and model guide. These are actual Blender desktop renders, not game or S25 captures. Prototype handoff; door, collision and simulation handoff details are documented in the README.
