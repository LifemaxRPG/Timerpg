# G016 review, round 1 (Claude): the look is right; it doesn't build yet

**The look:** your proof sheet is excellent.
- Hard dusk bands from ember to cobalt.
- The crescent beside the clock tower.
- A world-fixed starfield that holds at 0°, 45° and 90°.
- Flat-based pixel clouds, an overcast that reads as weather, and a full moon with a halo.
This is the pixel-art sky the game wants.

One look note: at noon (shot 02) the bands show faint radial wedges, straight seams from the zenith down. Probably the
azimuth quantisation in the band or haze term. The bands should be level rings with no spokes.

**The build:** compiled and run on the build server (Filament 1.81 `matc`, Kotlin 2.x), it fails in two places. Your
sandbox can't compile, so here are the exact errors.

1. **`sky.mat` doesn't compile:** `ERROR: 0:120: syntax error, unexpected FLOATCONSTANT`.
   - Cause: `const float PI = ...;`. Filament's shader prelude already `#define`s `PI`, so the line becomes
     `const float 3.14159... = ...`.
   - Fix: rename to `SKY_PI` and `SKY_TWO_PI`. With only that change it compiles cleanly (checked here); keep the
     rest.
   - Also rename the inner `SKY_BANDS` at line 260, which shadows the outer one.
2. **The Kotlin doesn't compile:**
   - `scene.removeEntity(...)` doesn't exist in our Filament Java API. It's `scene.remove(entity)`, as in
     `OceanSurface.kt:319`. This affects `SkySurface.kt:244` and `FilamentSkyPreview.kt:317, 482, 497`.
   - `SkySurface.kt:376`: `bakeCloudPixels` uses `CLOUD_TEX_SIZE`, which no longer exists. Your texture is now
     `CLOUD_TEX_W` × `CLOUD_TEX_H` (512×256), but this function still bakes a square. The overload errors at 386, 392,
     396 and 431 all follow from `s` being undefined.
   - Important: this means the Kotlin cloud bake is an older version than the Node port that made your proof
     renders. Port your final round-3 panorama bake (the one in the proof sheet) back into `bakeCloudPixels`, writing
     the full 512×256, so the game draws what the sheet shows.
3. With those fixed, `SkyStateTest` and `-Dmode=sky` can run here, and Claude will render the real Filament version
   beside your proof sheet.
