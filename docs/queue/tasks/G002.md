# G002: Ocean water prototype for Filament

- Assignee: gemini
- Type: engineering
- Branch: `gemini/G002-ocean`
- Status: accepted

## Brief
The game will have real oceans (ship and sailboat travel between continents). Build the ocean surface as a
standalone prototype in our Filament renderer, in our art style (pixel-art look, not photoreal):
- A new Filament material `kotlin-street/filament/materials/ocean.mat` (compile to
  `kotlin-street/app/src/main/assets/filament/ocean.filamat` with the repo's `matc` the same way street_lit.mat is
  built; see kotlin-street/filament/TRIAL.md).
- Waves: a sum of 4-6 Gerstner waves in the vertex shader (direction, wavelength, amplitude, steepness as
  parameters), on a grid mesh around the camera that moves with it (snap to grid steps so it doesn't swim).
- Colour by depth and angle in 3-4 flat stepped bands (pixel-art shading, no smooth gradients); white foam pixels on
  wave crests (by height/steepness), dithered; a sun glint band; sky colour reflection by time of day; night: dark
  with moon glint.
- A CPU-side function `OceanWaves.height(x, z, t)` that returns the same wave height and normal as the shader, so a
  boat can float on it later (Jolt buoyancy will use it).
- A desktop preview mode `-Dmode=ocean` in a NEW file `kotlin-street/desktop/src/filament/kotlin/FilamentOceanPreview.kt`
  showing open sea by day, dusk and night, calm and rough, with a simple box "boat" bobbing using
  OceanWaves.height.

## Acceptance
- New files only, plus one line to register the preview mode in kotlin-street/desktop/build.gradle.kts if needed. Do
  not change FilamentTown or any town code.
- A unit test that the CPU height matches the shader formula at sample points (port the formula to Kotlin once and
  test it).
- Renders (calm/rough × day/dusk/night, and the bobbing box) in `prototypes/ocean/`, stated as desktop renders.
- Per-frame GPU/CPU cost noted from the preview.
