# C014: Roadside motel

- Assignee: chatgpt
- Type: model
- Branch: `codex/C014-motel`
- Status: hold

## Why it matters
The new highway system (Highways v2) puts motels at interchanges and along the old routes, and towns everywhere need them. A **standard** building: set `"naming": "owner"` so the game paints each motel's own name (docs/SIGNS.md).

## Brief
An original single-storey L- or U-shaped motor court with rooms opening onto a covered walkway, an office with a check-in counter, and a tall roadside sign with a name panel. States:
1. **1935-1955 motor court:** separate cabins or a long timber row, carports.
2. **1955-1985 motel:** a long row with doors facing the parking lot, a kidney-shaped pool behind a fence, an ice machine, a big neon arrow sign with "VACANCY / NO" (lit separately).
3. **1985 onward:** a two-storey exterior-corridor budget motel with an outdoor stair, a plastic backlit sign, and ice and vending alcoves. Or the same row run-down.

Must have:
- room doors as named nodes (`room_<n>`), each with a bed anchor and a door anchor;
- the office counter with clerk and guest anchors;
- the pool as a separate node;
- the sign's name area documented.
