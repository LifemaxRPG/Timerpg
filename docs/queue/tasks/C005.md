## Brief

spinning pole (its own node `barber_pole` so the game can spin it), three chairs as fixed geometry, mirrors; and a
beauty parlour with hood dryers. States 1940-1979, 1980-2009 (refaced), 2010+ (a modern barbershop revival / nail
salon).
