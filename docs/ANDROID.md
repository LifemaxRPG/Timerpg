# Building the Android app

The game is a web app (Phaser + Vite). [Capacitor](https://capacitorjs.com) wraps the built web files in a
native Android shell. The Android project is in `android/` (generated by `npx cap add android`).

## What you need (on your own computer)
- Node 20+ and this repo: `npm install`
- [Android Studio](https://developer.android.com/studio) (it brings the Android SDK and a JDK)
- A phone with USB debugging on, or an emulator made in Android Studio

## Steps
1. `npm run android:sync` - builds the web app into `dist/` and copies it into the Android project.
2. `npm run android:open` - opens the project in Android Studio.
3. In Android Studio press **Run** (the green triangle), pick your phone/emulator.
4. After changing the game code, run step 1 again, then Run again.

To make a shareable APK: Android Studio -> Build -> Build Bundle(s) / APK(s) -> Build APK(s).
(A Play Store release needs a signing key: Build -> Generate Signed Bundle / APK.)

## Notes
- The sprites in `public/assets/` are LimeZu's (purchased). They end up inside the APK. Check the pack licenses
  before publishing the app anywhere.
- Orientation: the game works in portrait and landscape. To lock landscape, add
  `android:screenOrientation="sensorLandscape"` to the `<activity>` in `android/app/src/main/AndroidManifest.xml`.
- Controls on a phone: left thumb = joystick, tap a building to act on it, pinch (or the +/- buttons) to zoom,
  the year slider and its arrows are the time machine.
- Not yet verified on a real device: this was set up and tested in a desktop browser with a phone-sized touch screen.
  Performance on low-end phones (many sprites on screen) is the main thing to watch.
